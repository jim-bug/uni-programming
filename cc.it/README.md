# CyberChallenge.IT

Raccolta di test e soluzioni sviluppate per prepararsi ai test di programmazione di CyberChallenge.IT. Per ogni test proposto c'è una cartella dedicata con i relativi file di soluzione.

## Convenzioni

- **Data / nome cartella:** formato `YYYY-{Type}Test` (es. `2023-ProgrammingTest`)
- **Numerazione soluzioni:** riparte da `1` per ogni cartella
- **Titolo esercizio:** `Programming Test YYYY - NN (data di svolgimento) - Titolo`

## Elenco Svolgimenti

### Programming Test 2023 - 01 (2026-06-01) - Conteggio Corrispondenze per Posizione

- **Link traccia:** [Apri traccia ufficiale](https://cyberchallenge.it/media/public/training/2023-pretest.pdf)
- **Link soluzione:** [Apri soluzione](./2023-ProgrammingTest/solution1.py)
- **Descrizione:** Dato un codice corretto e una serie di sequenze candidate, il programma conta quante posizioni coincidono tra la sequenza corretta e ciascuna sequenza analizzata.
